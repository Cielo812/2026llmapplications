# 配图存放与引用

各词条配图放在以两位词条序号命名的子目录中。例如，09 号词条的图放在 `figure/09/`，使用 `rag-flow.png`、`retrieval-example.png` 等能说明内容的文件名。

从根目录中的词条文件引用图片：

```markdown
![图1：检索增强生成的工作流程](figure/09/rag-flow.png)

图1：检索增强生成的工作流程。来源：作者自绘，2026-11-12。
```

上面的路径只是命名示例，仓库未附这张示例图片。上传实际图片后再插入正文。

- 自绘图标注“作者自绘”；改绘图注明原始来源与改绘内容。
- 运行截图注明日期、模型或工具、对应任务，隐去密钥和个人信息。
- AI 生成的说明图注明生成方式，并核验图中概念与文字。
- 教学模拟图与真实运行截图分开说明。
- 仅提交与词条有关、具备使用权限的配图，避免上传无关或过大的文件。
